# TVC Preset Studio 제품 지침서

마지막 업데이트: 2026-09-15 (샴푸 광고 프리셋 추가)

## 제품 목적

제품 사진과 간단한 정보를 입력하면 광고 스타일을 선택하고 장면을 검토한 뒤 AI 광고 영상을 생성하는 서비스다. 최종 목표는 실제 웹 서비스로 배포하여 로그인, 사용량 관리, 크레딧 또는 결제까지 제공하는 것이다. 현재 로컬 버전도 이 목표를 막지 않는 구조로 개발한다.

## 핵심 사용자

1. 영상 제작 경험이 적은 소상공인과 자영업자
2. 자사 제품과 매장을 홍보하는 사업자
3. 광고 소재를 빠르게 만들어야 하는 마케터
4. 일반 AI 영상 제작 사용자

사용자가 영상 모델이나 프롬프트 구조 같은 전문 용어를 몰라도 광고를 만들 수 있어야 한다.

## 핵심 작업 흐름

1. 광고 목적 또는 업종 선택
2. 썸네일을 보고 광고 무드 선택
3. 사용자 제품 사진과 핵심 정보 입력
4. AI가 제안한 광고 컨셉 검토와 수정 요청
5. 컷별 스토리보드, 카메라와 나레이션 검토·수정
6. AI 영상 결과의 변동성, 예상 시간과 크레딧 확인
7. 최종 동의 후 영상 생성

첫 화면에서는 중요한 선택만 보여준다. 전문 설정은 필요할 때 펼치는 방식으로 제공한다.

## UI 원칙

- 설명보다 썸네일과 예시 결과로 기능을 이해할 수 있어야 한다.
- 한 화면에 선택지를 지나치게 많이 노출하지 않는다.
- 버튼 이름은 행동과 결과를 함께 표현한다.
- 모델명보다 사용자가 얻는 결과를 먼저 표시한다.
- 유료 요청 전에는 비용 발생 여부와 사용 크레딧을 명확히 표시한다.
- 실패 원인, 재시도 가능 여부, 크레딧 처리 상태를 쉬운 말로 보여준다.
- 모바일과 데스크톱에서 같은 작업 흐름을 유지한다.
- 접근 가능한 대비, 키보드 조작, 명확한 선택 상태를 유지한다.

## 분류 체계

- 업종: 뷰티, 음식·카페, 패션, 전자제품, 생활용품, 건강, 반려동물, 매장·공간, 서비스
- 광고 목적: 신제품 출시, 판매 전환, 브랜드 소개, 사용법, 프로모션, 매장 방문, 후기·신뢰
- 영상 분위기: 고급스러움, 밝고 깨끗함, 역동적, 감성적, 자연 친화적, 기술적, 재미있는 스타일

현재의 뷰티·제품·음식은 초기 업종 분류다. 업종, 광고 목적, 분위기를 한 종류의 카테고리에 섞지 않는다.

## 참조 이미지 원칙

- 사용자 제품 사진이 광고 대상의 최우선 기준이다.
- 프리셋 썸네일에는 샘플 제품과 인물이 보여도 된다.
- 썸네일에서는 조명, 배경, 구도, 색감, 카메라 리듬을 주로 가져온다.
- 생성 지침에는 썸네일의 샘플 제품을 사용자 제품으로 교체한다고 명확하게 적는다.
- 참조 전달 순서는 사용자 제품 → 선택한 출연 모델 → 프리셋 광고 무드로 유지한다.
- 제품 형태, 로고, 라벨, 인물 일관성을 생성 결과에서 검토할 수 있어야 한다.

## 실제 배포를 위한 기술 원칙

현재 프런트엔드와 프롬프트 자산은 유지하면서 운영 백엔드를 교체할 수 있어야 한다.

- API 키는 브라우저에 포함하지 않고 서버에서만 관리한다.
- 로그인 후 사용자와 조직 단위로 프로젝트와 자산을 분리한다.
- 제품·모델 이미지와 결과 영상은 객체 저장소에 보관하고 만료 정책을 둔다.
- DB에는 사용자, 조직, 프로젝트, 자산, 생성 작업, 사용량, 결제 원장을 분리해 기록한다.
- 영상 생성은 작업 큐에서 처리하고 동시 실행 제한, 재시도, 취소, 웹훅을 지원한다.
- 생성 요청마다 공급사 작업 ID, 모델, 비용, 상태와 오류를 기록한다.
- 결제와 크레딧 차감은 서버에서 검증하며 중복 요청에도 한 번만 처리되게 한다.
- 업로드 형식, 크기, 권한, 악성 파일을 서버에서 검사한다.
- 운영 로그에 API 키나 원본 이미지 데이터를 남기지 않는다.

## 비용 및 결제 UX

- 생성 전 예상 크레딧 또는 가격을 보여준다.
- 버튼 중복 클릭으로 결제가 반복되지 않게 한다.
- 생성 실패 시 환불, 자동 재시도 또는 사용자 재시도 규칙을 명확히 한다.
- 저해상도 미리보기와 최종 고품질 생성의 가격을 분리할 수 있게 설계한다.
- 관리자 화면에서 공급사 비용, 사용자 매출, 실패율을 확인할 수 있어야 한다.

## 향후 쇼츠 자동화

쇼츠 자동화는 별도 기능이지만 TVC와 같은 브랜드 자산을 공유한다.

- 제품 판매 쇼츠
- 매장 홍보 쇼츠
- 정보형·교육형 쇼츠
- 후기와 사용법 쇼츠
- 여러 대본과 영상을 일괄 생성하는 캠페인

공통 브랜드 보관함에는 로고, 브랜드 색상, 제품 사진, 출연 모델, 금지 표현, 자주 쓰는 문구와 생성 결과를 저장한다.

## V1·V2 홈페이지 운영

- V2 홈페이지와 작업창에 로컬 페이퍼로지 웹폰트를 사용한다.
- 작업창 상단에 정보 입력 → 컨셉 검토 → 스토리보드 검토의 3단계 진행선을 표시하고 현재 단계와 완료 단계를 구분한다.
- 장면 구성하기 이후에도 기존 왼쪽 미디어 영역의 위치와 크기를 유지하고 오른쪽 입력 영역만 검토 화면으로 전환한다. 작은 화면에서는 같은 미디어 영역을 상단에 유지한다.

- 컨셉·스토리보드 검토는 기존 제작 팝업 안에서 전환되며 팝업 크기와 흐린 홈페이지 배경을 유지한다. 검토 화면을 닫으면 입력값을 보존한 제품 입력 단계로 돌아간다.

- 2026-09-10까지의 기존 홈페이지는 index-v1.html과 V1 전용 자산으로 보존한다.
- 기본 진입점 index.html은 Start TVC Studio V2로 운영한다.
- START-TVC-STUDIO.cmd 실행 시 V1 또는 V2를 먼저 선택하고 해당 주소를 연다.
- V2 프리셋 제작은 별도 페이지로 이동하지 않고 홈페이지 위 모달에서 시작한다.
- 프리셋 카드는 이미지 영역을 포함한 카드 전체 클릭과 키보드 Enter·Space로 제작 모달을 연다.
- 홈페이지 프리셋과 제작 모달 미디어 영역은 향후 영상 자산을 재생할 수 있는 16:9 프레임을 기본으로 한다.
- 제작 모달의 입력 영역은 고정된 하단 실행 버튼과 독립 스크롤을 사용해 모든 단계를 볼 수 있게 한다.
- 제작 모달은 선택형 제품 이미지 최대 5장, 선택형 남녀 모델, 가로·세로 비율, 제품 링크 기반 나레이션, 변경하지 않음·로맨틱·코믹 스타일, 선택형 로고 입력을 제공한다.
- 모델 라이브러리는 assets/tvc-models/female 및 male 폴더의 이미지를 서버에서 읽어 성별 탭별로 표시한다.
- 모델을 따로 선택하지 않으면 선택한 프리셋 썸네일의 모델을 기본으로 사용한다.
- 모델 선택 카드는 원본 이미지의 가로·세로 비율에 따라 높이를 자동 결정하고 이미지 전체를 표시한다. 목록 행은 콘텐츠 높이를 유지하고 스크롤하며 모델명도 카드 아래에 표시한다.
- 제품 업로드 미리보기도 원본 비율을 유지하고 전체 이미지를 표시한다. 참조 이미지에는 영상용 16:9 프레임이나 잘라 채우기를 적용하지 않는다.
- 제품·로고 이미지는 현재 브라우저 메모리에서만 미리보기하며 영구 저장하지 않는다.
- 제품 이미지가 없어도 장면 구성하기를 누르면 파일 선택창을 강제로 열지 않고 현재 탭의 컨셉 검토 단계로 진행한다.
- V2 입력 완료 후 채팅형 검토 화면에서 컨셉을 먼저 승인하고, 5컷 스토리보드의 장면 설명을 직접 수정하거나 채팅으로 수정 요청할 수 있다.
- 스토리보드 확정 후에는 AI 생성 결과의 불규칙성, 예상 소요 시간과 크레딧을 명시한 최종 동의창을 표시한다.
- 현재 V2 검토 화면은 프런트엔드 상호작용 단계이며 최종 동의 버튼은 유료 생성 API나 크레딧 차감과 아직 연결하지 않는다.
- 모델 선택 완료 후 안내 아래에 선택한 모델의 작은 이미지를 표시하며, 로고 업로드 아래에도 동일한 원본 비율 미리보기를 표시한다. 각 미리보기의 × 버튼으로 선택을 해제할 수 있고, 모델 해제 시 썸네일 모델 사용으로 돌아간다. 로고 교체·해제 시 이전 임시 이미지 URL을 해제한다.
## 현재 구현 상태

- V2 모달 제작 흐름이 적용된 반응형 서비스 홈페이지
- V1 홈페이지를 index-v1.html로 보존
- 업종 필터가 TVC·쇼츠 프리셋 레일에 함께 적용되는 탐색 UI
- 사례, 가격 가안, FAQ와 제작 화면 연결
- 기존 제작 화면은 studio.html로 분리하여 홈페이지 변경과 충돌하지 않게 유지
- 독립 로컬 서버: 기본 포트 8065
- 뷰티·제품·음식 카테고리와 프리셋 UI
- 제공된 참조 이미지를 사용하는 15초·6컷 샴푸 광고 TVC 프리셋
- 프리셋 썸네일 및 폴더 기반 출연 모델 선택
- 제품 이미지 최대 6장
- 로컬 장면 초안과 편집 가능한 세 장면
- Seedance 2.5 단일·다중 참조 생성
- WaveSpeed 작업 상태 조회 및 브라우저 생성 기록
- 제품을 최우선 참조로 지정하는 프롬프트

현재 제품 사진과 생성 기록은 브라우저 저장소에 보관된다. 운영 배포 전에는 인증된 서버 저장 방식으로 교체해야 한다.

## 우선 개발 순서

1. 프리셋과 예시 결과 확충
2. 초보 사용자 대상 작업 흐름 사용성 검증
3. 브랜드 보관함과 프로젝트 저장
4. 인증, 사용자·조직 데이터 분리
5. 작업 큐와 생성 비용 기록
6. 크레딧 및 결제
7. 운영 관리자 화면
8. 쇼츠 자동화

## 문서 업데이트 규칙

기능, 화면 흐름, 대상 사용자, 분류 체계, API 연동, 저장 방식, 결제 정책 또는 로드맵이 달라질 때 이 문서를 같은 작업에서 함께 수정한다.

- 마지막 업데이트 날짜를 변경한다.
- 현재 구현 상태를 실제 코드와 맞춘다.
- 완료한 다음 진행할 작업의 우선순위를 반영한다.
- 폐기된 계획은 남겨두지 않고 현재 결정으로 교체한다.
- API 키, 비밀번호, 사용자 개인정보는 기록하지 않는다.
