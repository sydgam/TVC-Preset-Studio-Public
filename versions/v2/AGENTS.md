# Project working rules

Before changing this project, read PROJECT_GUIDE.md.

- Build toward a deployable, paid service for small businesses, business owners, marketers, and general AI-video users.
- Keep the primary workflow visual, simple, and understandable without AI-video expertise.
- Keep provider API keys and billing decisions on the server.
- Preserve a path toward authenticated, tenant-separated storage, job queues, usage accounting, and payments.
- Plan TVC and future Shorts automation around shared brand assets.

When a change affects product behavior, UI flow, audience, categories, API integration, storage, billing, security, current implementation, or roadmap, update PROJECT_GUIDE.md in the same task and change its last-updated date.

Do not write secrets or personal user data into documentation, fixtures, logs, or browser code.
