# TVC 프리셋 썸네일

아래 경로와 파일명을 그대로 사용하면 `TVC_Preset` 화면에 자동 표시됩니다.
권장 형식은 PNG 또는 WebP, 권장 비율은 16:9, 권장 크기는 960×540 이상입니다.
썸네일에 샘플 제품이나 인물이 포함되어도 됩니다. 생성 시 썸네일은 조명·배경·구도·모델 무드 참조로 쓰고, 샘플 제품은 사용자가 올린 제품으로 교체하도록 지침을 전달합니다.

## 뷰티 `beauty/`

- `luminous-serum.png` — 루미너스 세럼
- `noir-perfume.webp` — 블랙 퍼퓸
- `botanical-care.webp` — 보태니컬 케어

## 제품 `product/`

- `tech-reveal.png` — 테크 리빌
- `minimal-object.webp` — 미니멀 오브젝트
- `dynamic-launch.webp` — 다이내믹 런치

## 음식 `food/`

- `fresh-table.png` — 프레시 테이블
- `sizzle-macro.webp` — 시즐 매크로
- `moody-cafe.webp` — 무드 카페

파일이 없을 때는 해당 프리셋의 색상 그래픽이 대신 표시됩니다.
썸네일은 실제 결과 영상에서 뽑은 대표 프레임을 사용하는 것이 가장 정확합니다.
